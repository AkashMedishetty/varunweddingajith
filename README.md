# Varun & Bhavani — Wedding Invitation

A cinematic, scroll-driven wedding invitation (static site).

## Deploy
Static site: `index.html` at the root with an `assets/` folder. Deploy on
Vercel (Framework: **Other**, no build command, output = root) or any static host.

## Structure
- `index.html` — the invite
- `assets/` — images, CSS, JS, fonts, audio
- `tools/` — asset-prep scripts (not needed at runtime)

`raw/` source images are git-ignored to keep the repo light.
